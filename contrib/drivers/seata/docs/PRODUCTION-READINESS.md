## 5. 已知限制

### 5.1 功能限制

#### 1. 数据库支持有限
**限制**: 仅支持 MySQL  
**影响**: 无法用于 PostgreSQL、Oracle 等数据库  
**解决方案**: 后续版本扩展支持

#### 2. 复杂 SQL 支持不完整
**限制**: 不支持子查询、JOIN、聚合函数等复杂 SQL  
**影响**: 复杂业务场景可能失败  
**解决方案**: 逐步完善 SQL 解析器

#### 3. XA 模式测试不足
**限制**: XA 模式缺少充分测试  
**影响**: 生产使用风险较高  
**解决方案**: 补充 XA 模式测试用例

### 5.2 性能限制

#### 1. 一阶段性能开销
**限制**: Image 生成带来 2-3 倍性能开销  
**影响**: 高并发场景性能下降  
**解决方案**: 
- 启用异步提交
- 使用 `OnlyCarePrimaryKey` 减少 Image 大小
- 优化 SQL 解析

#### 2. 回滚性能较低
**限制**: 二阶段回滚需要读取 Undo Log 并执行补偿 SQL  
**影响**: 回滚操作较慢（50ms+）  
**解决方案**: 优化回滚 SQL 生成逻辑

### 5.3 稳定性限制

#### 1. 长时间运行未验证
**限制**: 缺少 7x24 小时稳定性测试  
**影响**: 可能存在内存泄漏、连接泄漏等问题  
**解决方案**: 
- 进行长时间压力测试
- 监控内存和连接池

#### 2. 异常场景覆盖不足
**限制**: 网络分区、Seata Server 宕机等场景未充分测试  
**影响**: 异常情况下行为不确定  
**解决方案**: 补充混沌工程测试

## 6. 部署建议

### 6.1 环境准备

#### 6.1.1 Seata Server 部署

**推荐配置**:
```yaml
# 生产环境 Seata Server 配置
server:
  service-port: 8091
  
store:
  mode: db  # 使用数据库存储
  db:
    datasource: druid
    db-type: mysql
    driver-class-name: com.mysql.jdbc.Driver
    url: jdbc:mysql://127.0.0.1:3306/seata?useSSL=false
    user: seata
    password: seata
    min-conn: 5
    max-conn: 100
    
registry:
  type: nacos  # 推荐使用 Nacos
  nacos:
    application: seata-server
    server-addr: 127.0.0.1:8848
    namespace: ""
    cluster: default
```

**高可用部署**:
- 至少 3 个 Seata Server 节点
- 使用 Nacos 做服务发现
- 数据库做主从复制

#### 6.1.2 数据库准备

```sql
-- 1. 创建 undo_log 表
CREATE TABLE `undo_log` (
  `id` bigint(20) NOT NULL AUTO_INCREMENT,
  `branch_id` bigint(20) NOT NULL,
  `xid` varchar(100) NOT NULL,
  `context` varchar(128) NOT NULL,
  `rollback_info` longblob NOT NULL,
  `log_status` int(11) NOT NULL,
  `log_created` datetime NOT NULL,
  `log_modified` datetime NOT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `ux_undo_log` (`xid`,`branch_id`),
  KEY `idx_log_created` (`log_created`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8;

-- 2. 定期清理历史数据（建议每天执行）
DELETE FROM undo_log 
WHERE log_status = 1 
AND log_modified < DATE_SUB(NOW(), INTERVAL 7 DAY)
LIMIT 10000;
```

#### 6.1.3 应用配置

**推荐生产配置**:
```yaml
seata:
  enabled: true
  application-id: "my-app-prod"
  tx-service-group: "prod_tx_group"
  mode: "AT"
  
  at:
    enable-async-commit: true      # 启用异步提交
    only-care-primary-key: true    # 只关注主键（性能优化）
    undo-log-serialization: "json"
    undo-log-table: "undo_log"
  
  fallback:
    enabled: true                  # 启用降级
    strategy: "to-local"           # 降级到本地事务
    error-threshold: 5             # 5次错误后降级
    time-window: 60                # 60秒时间窗口
    recovery-timeout: 30           # 30秒后恢复
  
  retry:
    max-attempts: 3                # 最多重试3次
    interval: 100                  # 初始间隔100ms
    max-interval: 1000             # 最大间隔1秒
    multiplier: 2.0                # 指数退避
```
